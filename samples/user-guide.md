# User Guide: Export a Report

## Purpose

This guide demonstrates a report export procedure in a fictional enterprise application.

## Prerequisites

- Sign in to the application.
- Open a report that contains data.
- Confirm that your role permits report export.

## Procedure

1. Open the Reports section.
2. Select the report you want to export.
3. Review the report data.
4. Select Export.
5. Choose CSV, if that option is available.
6. Save the exported file to your preferred location.

## Expected Result

A CSV file is saved to the selected location if the
application supports this export option and the
operation completes successfully.

## Troubleshooting

**The export option is unavailable.**

Confirm your permissions and check whether the selected report supports export.

**The exported file contains unexpected data.**

Review the report filters and compare the exported contents with the report displayed in the application.
